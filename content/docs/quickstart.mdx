title: Quickstart
description: Define HTTP routes with handlers and call them through a typed client.
---

`rest-rpc` builds REST APIs with RPC-like ergonomics: an HTTP route builder
with sensible defaults, and a typed client to call the routes.

This guide uses Node's `node:http` server and Zod to build two routes: a minimal create operation
and a GET with path params, query input, and success/error responses.
Their response types are inferred from the handlers.

## Install

```package-install
npm i @rest-rpc/core @rest-rpc/server zod
```

Use an existing TypeScript project with a `tsconfig.json`. For fetch-native
runtimes such as Bun, Deno, and Cloudflare Workers, see the
[Fetch runtime](/docs/server/fetch). To use an existing framework's router, see
[Frameworks](/docs/server/frameworks).

## Define Routes

```ts routes.ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

type Todo = { id: string; title: string; completed: boolean };
const todos = new Map<string, Todo>();

const create = route
	.body(z.object({ title: z.string().min(1) }))
	.handler(({ body: { title } }) => {
		const todo: Todo = {
			id: crypto.randomUUID(),
			title,
			completed: false,
		};
		todos.set(todo.id, todo);
		return todo;
	});

const get = route
	.get("/todos/:id")
	.params(z.object({ id: z.string() }))
	.query(z.object({ uppercase: z.enum(["yes", "no"]).optional() }))
	.handler(({ params, query }) => {
		const todo = todos.get(params.id);
		if (!todo) {
			return { status: 404, body: { code: "TODO_NOT_FOUND" as const } };
		}
		return {
			...todo,
			title: query.uppercase === "yes" ? todo.title.toUpperCase() : todo.title,
		};
	});

export const routes = { todos: { create, get } };
```

`todos.create` uses `POST /todos/create`, reads a JSON body, and returns the
todo as a 200 response. `todos.get` uses `GET /todos/:id?uppercase=yes` and
returns either the todo with status 200 or a 404 envelope.

The request schemas validate inputs, and the handler's return value determines
the client's result type.

## Register Routes

```ts server.ts
import { createServer } from "node:http";
import { compileRoutes, createCatchAllHandler } from "@rest-rpc/server/node";
import { routes } from "./routes";

const handler = createCatchAllHandler(compileRoutes(routes));

createServer(async (req, res) => {
	const { matched } = await handler(req, res);
	if (!matched) res.writeHead(404).end();
}).listen(3000);
```

`compileRoutes` prepares the routes once. The catch-all handler routes each
request to the matching route, or reports `matched: false` so the server can
respond otherwise.

## Create the Client

Extract a minimal contract from the routes at build time, and import it with
the route tree type:

```ts extract-contract.ts
import { writeFile } from "node:fs/promises";
import { extractContract } from "@rest-rpc/core";
import { routes } from "./routes";

await writeFile("contract.json", JSON.stringify(extractContract(routes)));
```

```ts client-contract.ts
import type { routes } from "./routes";
import contract from "./contract.json";

export const api = contract as unknown as typeof routes;
```

See [Client Contract Extraction](/docs/client/contract-extraction) for bundler
setups.

## Call the Routes

```ts client.ts
import { initClient } from "@rest-rpc/core";
import { api } from "./client-contract";

const client = initClient(api, { baseUrl: "http://localhost:3000" });

const created = await client.todos.create({ body: { title: "Write docs" } });
const response = await client.todos.get({
	params: { id: created.body.id },
	query: { uppercase: "yes" },
});

if (response.status === 200) {
	console.log(response.body.title);
} else {
	console.log(response.body.code); // "TODO_NOT_FOUND"
}
```

The calls are typed functions, while the requests still use the methods, URLs,
query parameters, and statuses you defined. Other HTTP clients can call the same
endpoints.
