Each package's reference is generated from its source and TSDoc comments, on
npmx.dev:

- [`@rest-rpc/core`](https://npmx.dev/package-docs/@rest-rpc/core/): route
  definitions, the Fetch client, OpenAPI and contract extraction.
- [`@rest-rpc/server`](https://npmx.dev/package-docs/@rest-rpc/server/):
  handlers, validation and serving, on Fetch from the root and on Node from
  `@rest-rpc/server/node`.
- [`@rest-rpc/tanstack-query`](https://npmx.dev/package-docs/@rest-rpc/tanstack-query/):
  TanStack Query options and keys.
