`@rest-rpc/server` serves routes with Fetch `Request` and `Response`, on
fetch-native runtimes such as Bun, Deno, and Cloudflare Workers. See
[Serving Routes](/docs/server/overview) for what is shared with
[Node](/docs/server/node), and [Framework Integration](/docs/server/framework-integration)
to add the routes to a framework such as Hono.

## Usage

`createApp` turns a route tree into an app with a `fetch` handler. Runtimes such
as Bun, Deno, and Cloudflare Workers serve it when it is the default export. The
app also has `routes` in the format of Bun's `routes` server option, so on Bun
the requests are routed by Bun's native router:

```ts server.ts
import { createApp, route } from "@rest-rpc/server";
import { z } from "zod";

const todos = new Map([["todo_1", { id: "todo_1", title: "Write docs" }]]);

const getTodo = route
	.get("/todos/:id")
	.params(z.object({ id: z.string() }))
	.error("TODO_NOT_FOUND", { status: 404 })
	.handler(({ params, errors }) => {
		const todo = todos.get(params.id);
		if (!todo) throw errors.TODO_NOT_FOUND();
		return todo;
	});

export const routes = { todos: { get: getTodo } };

export default createApp(routes);
```

:::tip[Bun Server Options]
To set other Bun server options, spread the app into `Bun.serve()`, and spread
`app.routes` to add your own routes:

```ts server.ts
const app = createApp(routes);

Bun.serve({
	...app,
	port: 8080,
	routes: { ...app.routes, "/health": new Response("ok") },
});
```

:::

## App Options

`createApp` takes the [route options](/docs/server/overview#route-options) and
these:

```ts
type CreateAppOptions = {
	mountPath?: AbsolutePath;
	// Required when the routes declare initial context.
	context?:
		| TContext
		| ((request: Request, ...args: TArgs) => TContext | Promise<TContext>);
	interceptors?: readonly Interceptor[];
};
```

- `mountPath`: the path the routes are served under, such as `/api`. See
  [Mount Path](/docs/server/overview#mount-path).
- `context`: the [initial context](/docs/middleware#values-from-the-host) the
  routes declare, or a function, sync or async, that returns it for each
  request. It is required when the routes declare initial context, and must
  satisfy the initial context of every route. If the function throws, the
  response is an `INTERNAL_SERVER_ERROR`.

  ```ts
  createApp(routes, {
  	context: async (request) => ({ db, headers: request.headers }),
  });
  ```

  The function also receives what the runtime passes to `fetch` after the
  request, such as the `env` bindings of Cloudflare Workers or the connection
  info of Deno. Their types are inferred from the function's parameters:

  ```ts
  export default createApp(routes, {
  	context: (request, env: Env) => ({ db: env.DB }),
  }) satisfies ExportedHandler<Env>;
  ```

- `interceptors`: functions around everything the app does for a request. See
  [Interceptors](/docs/server/interceptors).

Thrown errors are sent as [error responses](/docs/http-behavior/errors), and
requests that match no route as `NOT_FOUND`.
