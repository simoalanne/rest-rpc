title: Fetch
description: Serve rest-rpc routes with Fetch Request and Response

`@rest-rpc/server` serves routes with Fetch `Request` and `Response`, on
fetch-native runtimes such as Bun, Deno, and Cloudflare Workers.

## Usage

`createApp` turns a route tree into an app with a `fetch` handler. Runtimes such
as Bun, Deno, and Cloudflare Workers serve it when it is the default export. The
app also has `routes` in the format of Bun's `routes` server option, so on Bun
the requests are routed by Bun's native router:

```ts server.ts
import { createApp, route } from "@rest-rpc/server";
import * as z from "zod";

const posts = new Map([
	["post_1", { id: "post_1", title: "Hello", body: "First post" }],
]);

const get = route
	.get("/posts/:id")
	.params(z.object({ id: z.string() }))
	.error("POST_NOT_FOUND", { status: 404 })
	.handler(({ params, errors }) => {
		const post = posts.get(params.id);
		if (!post) throw errors.POST_NOT_FOUND();
		return post;
	});

export const router = { posts: { get } };

export default createApp(router);
```

:::tip[Bun Server Options]
To set other Bun server options, spread the app into `Bun.serve()`, and spread
`app.routes` to add your own routes:

```ts server.ts
const app = createApp(router);

Bun.serve({
	...app,
	port: 8080,
	routes: { ...app.routes, "/health": new Response("ok") },
});
```

:::

## App Options

`createApp` takes the [route options](/docs/server/overview#route-options) and
these:

```ts
type CreateAppOptions = {
	/**
	 * The path the routes are served under, such as `/api`. Route paths do not
	 * include it.
	 */
	mountPath?: AbsolutePath;
	/**
	 * The initial context the routes require for each request, or a function
	 * that returns it for the request. Required when the routes require initial
	 * context, and must satisfy the initial context of every route. If the
	 * function throws, the response is an `INTERNAL_SERVER_ERROR`.
	 */
	context?:
		| TContext
		| ((request: Request, ...args: TArgs) => TContext | Promise<TContext>);
	/**
	 * Functions around everything the app does for a request, the first
	 * outermost. They run after the route is matched and before it runs, for
	 * Bun's native `routes` too.
	 */
	interceptors?: readonly Interceptor[];
};
```

The `context` function also receives the arguments the runtime passes to `fetch` after the
request, such as the `env` bindings of Cloudflare Workers, with their types
inferred from its parameters:

```ts
export default createApp(router, {
	context: (request, env: Env) => ({ db: env.DB }),
}) satisfies ExportedHandler<Env>;
```

Thrown errors are sent as [error responses](/docs/http-behavior/errors), and
requests that match no route as `NOT_FOUND`.
