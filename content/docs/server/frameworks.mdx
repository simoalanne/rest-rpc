---
title: Frameworks
description: Register rest-rpc routes on an existing framework's router
---

rest-rpc does not provide framework-specific packages. Use the
[Fetch runtime](/docs/server/fetch) for frameworks built on Fetch `Request`,
such as Hono, or the [Node HTTP](/docs/server/node) runtime for frameworks built
on Node's `IncomingMessage`, such as Express.

Register each compiled route on the framework's [native router](#native-router),
or mount the [catch-all](#catch-all) handler and let rest-rpc do the routing.
Either way, pass framework values that handlers need, such as an authenticated
user, through the [`context` option](/docs/server/fetch#handle-options), and
params or a body the framework already parsed through `params` and `body`.

## Native Router

Register each compiled route's `method` and `path` on the framework's router
and call `route.handle()` from it. The framework does the routing.

<Tabs>
<Tab title="Hono">

```ts server.ts
import { Hono } from "hono";
import { compileRoutes } from "@rest-rpc/server";
import { routes } from "./routes";

const app = new Hono();

for (const route of compileRoutes(routes, {
	prefix: "/api",
	paramSyntax: "colon",
})) {
	app.on(route.method, route.path, (c) =>
		route.handle(c.req.raw, { context: { user: c.var.user } }),
	);
}
```

</Tab>
<Tab title="Express">

```ts server.ts
import express from "express";
import { compileRoutes } from "@rest-rpc/server/node";
import { routes } from "./routes";

const app = express();

for (const route of compileRoutes(routes, {
	prefix: "/api",
	paramSyntax: "colon",
})) {
	const method = route.method.toLowerCase() as
		"get" | "post" | "put" | "patch" | "delete";
	app[method](route.path, (req, res, next) => {
		route.handle(req, res).catch(next);
	});
}
```

</Tab>
</Tabs>

## Catch-all

Mount the catch-all handler on a single route or middleware. rest-rpc does the
routing and reports `matched: false` for requests it does not handle, so the
framework can continue with its own routes.

<Tabs>
<Tab title="Hono">

```ts server.ts
import { Hono } from "hono";
import { compileRoutes, createCatchAllHandler } from "@rest-rpc/server";
import { routes } from "./routes";

const app = new Hono();
const handler = createCatchAllHandler(
	compileRoutes(routes, { prefix: "/api" }),
);

app.all("/api/*", async (c) => {
	const result = await handler(c.req.raw, { context: { user: c.var.user } });
	return result.matched ? result.response : c.notFound();
});
```

</Tab>
<Tab title="Express">

```ts server.ts
import express from "express";
import { compileRoutes, createCatchAllHandler } from "@rest-rpc/server/node";
import { routes } from "./routes";

const app = express();
const handler = createCatchAllHandler(
	compileRoutes(routes, { prefix: "/api" }),
);

app.use((req, res, next) => {
	handler(req, res).then(({ matched }) => matched || next(), next);
});
```

Mount the catch-all without a path. `app.use("/api", ...)` strips the mount
path from `req.url`, so the requests no longer match the prefixed routes.

</Tab>
</Tabs>
