---
title: Contract-first Quickstart
description: Declare a shared HTTP interface, implement it, and use it in a typed client.
---

A separate contract is useful when the HTTP interface should be shared
independently of its implementation. Declare it with the core route builder,
implement it with `@rest-rpc/server`, and pass the same contract to the client.

This guide builds the same two routes as the [Quickstart](/docs/quickstart),
using Bun and Zod. The methods, paths, requests, statuses, and client
results are equivalent, but the response types are declared explicitly rather
than inferred from handlers.

## Install

```package-install
npm i @rest-rpc/core @rest-rpc/server zod
```

## Declare the Contract

Put the contract somewhere both server and client can import.

```ts contract.ts
import { route } from "@rest-rpc/core";
import { z } from "zod";

const todoSchema = z.object({
	id: z.string(),
	title: z.string(),
	completed: z.boolean(),
});

const create = route
	.body(z.object({ title: z.string().min(1) }))
	.response(todoSchema);

const get = route
	.get("/todos/:id")
	.params(z.object({ id: z.string() }))
	.query(z.object({ uppercase: z.enum(["yes", "no"]).optional() }))
	.response(todoSchema)
	.error("TODO_NOT_FOUND", { status: 404 });

export const api = { todos: { create, get } };
```

`todos.create` uses the default `POST /todos/create`. `todos.get` declares its
HTTP method, path, 200 response, and `TODO_NOT_FOUND` error with status 404. The schemas also provide runtime validation of handler results.

## Implement and Register Routes

```ts server.ts
import { createApp, implement } from "@rest-rpc/server";
import { api } from "./contract";

type Todo = { id: string; title: string; completed: boolean };
const todos = new Map<string, Todo>();

const create = implement(api.todos.create).handler(({ body: { title } }) => {
	const todo: Todo = {
		id: crypto.randomUUID(),
		title,
		completed: false,
	};
	todos.set(todo.id, todo);
	return todo;
});

const get = implement(api.todos.get).handler(({ params, query, errors }) => {
	const todo = todos.get(params.id);
	if (!todo) throw new errors.TODO_NOT_FOUND();
	return {
		...todo,
		title: query.uppercase === "yes" ? todo.title.toUpperCase() : todo.title,
	};
});

const routes = { todos: { create, get } };

Bun.serve({ ...createApp(routes), port: 3000 });
```

`implement()` keeps each handler's request and result tied to its declaration.
The contract itself contains no framework or handler code.

## Call the Routes

Import the shared contract directly. No contract extraction step is needed.

```ts client.ts
import { initClient, isDeclaredError, safe } from "@rest-rpc/core";
import { api } from "./contract";

const client = initClient(api, { baseUrl: "http://localhost:3000" });

const created = await client.todos.create({ body: { title: "Write docs" } });
const result = await safe(
	client.todos.get({
		params: { id: created.body.id },
		query: { uppercase: "yes" },
	}),
);

if (!result.error) {
	console.log(result.data.body.title);
} else if (
	isDeclaredError(result.error) &&
	result.error.code === "TODO_NOT_FOUND"
) {
	console.log(result.error.message);
}
```
