---
title: Contract-first Quickstart
description: Define a shared HTTP interface, implement it, and use it in a typed client.
---

A separate contract is useful when the HTTP interface should be shared
independently of its implementation. Define it with the core route builder,
implement it with `@rest-rpc/server`, and pass the same contract to the client.

This guide builds the same two routes as the [Quickstart](/docs/quickstart),
using Bun and Zod. The methods, paths, requests, statuses, and client
results are equivalent, but the response types are defined explicitly rather
than inferred from handlers.

## Install

```package-install
npm i @rest-rpc/core @rest-rpc/server zod
```

## Define the Contract

Put the contract somewhere both server and client can import.

```ts contract.ts
import { route } from "@rest-rpc/core";
import { z } from "zod";

const postSchema = z.object({
	id: z.string(),
	title: z.string(),
	body: z.string(),
});

const create = route
	.body(z.object({ title: z.string().min(1), body: z.string() }))
	.response(postSchema);

const get = route
	.get("/posts/:id")
	.params(z.object({ id: z.string() }))
	.query(z.object({ preview: z.enum(["true", "false"]).optional() }))
	.response(postSchema)
	.error("POST_NOT_FOUND", { status: 404 });

export const api = { posts: { create, get } };
```

`posts.create` uses the default `POST /posts/create`. `posts.get` defines its
HTTP method, path, 200 response, and `POST_NOT_FOUND` error with status 404. The schemas also provide runtime validation of handler results.

## Implement and Register Routes

```ts server.ts
import { createApp, implement } from "@rest-rpc/server";
import { api } from "./contract";

type Post = { id: string; title: string; body: string };
const posts = new Map<string, Post>();

const create = implement(api.posts.create).handler(
	({ body: { title, body } }) => {
		const post: Post = {
			id: crypto.randomUUID(),
			title,
			body,
		};
		posts.set(post.id, post);
		return post;
	},
);

const get = implement(api.posts.get).handler(({ params, query, errors }) => {
	const post = posts.get(params.id);
	if (!post) throw errors.POST_NOT_FOUND();
	return {
		...post,
		body: query.preview === "true" ? post.body.slice(0, 40) : post.body,
	};
});

const routes = { posts: { create, get } };

export default createApp(routes);
```

`implement()` keeps each handler's request and result tied to its definition.
The contract itself contains no framework or handler code.

## Call the Routes

Import the shared contract directly. No contract extraction step is needed.

```ts client.ts
import { createClient, isDefinedError, safe } from "@rest-rpc/core";
import { api } from "./contract";

const client = createClient(api, { origin: "http://localhost:3000" });

const created = await client.posts.create({
	body: { title: "Hello", body: "First post" },
});
const result = await safe(
	client.posts.get({
		params: { id: created.body.id },
		query: { preview: "true" },
	}),
);

if (!result.error) {
	console.log(result.data.body.title);
} else if (
	isDefinedError(result.error) &&
	result.error.code === "POST_NOT_FOUND"
) {
	console.log(result.error.message);
}
```
