---
title: Client Contract Extraction
description: Extract a minimal runtime contract from your server routes.
---

When you can't import your server code directly, such as for a browser bundle,
`extractContract()` gives the client a minimal runtime contract with the same types as your server routes.

:::tip[Using Contract-First?]
Import the [shared contract](/docs/contract-first) directly and skip this page.
:::

## Extract Routes with a Macro

Run it as a bundler macro so the bundle gets plain JSON:

```ts contract.ts
import { extractContract } from "@rest-rpc/core";
import { router } from "./router.ts";

export function getContract() {
	return extractContract(router);
}
```

```ts client.ts
import { createClient } from "@rest-rpc/core";
import { getContract } from "./contract" with { type: "macro" };

export const client = createClient(getContract());
```

In a browser, the client calls the page's origin. Pass the
[client options](/docs/client/fetch-client#client-options) for an API on
another origin or under a mount path.

Bun supports macros natively. For Vite, esbuild, Rolldown, Rollup, webpack or
Rspack, use [`unplugin-macros`](https://github.com/unplugin/unplugin-macros):

```ts vite.config.ts
import Macros from "unplugin-macros/vite";
import { defineConfig } from "vite";

export default defineConfig({
	plugins: [Macros()],
});
```

`router.ts` runs at build time, so keep it free of side effects like
starting the server or connecting to a database.

## Extract Routes without a Macro

For bundlers without macro support (e.g. Turbopack), write the contract to
JSON in watch mode:

```ts scripts/extract-contract.ts
import { writeFile } from "node:fs/promises";
import { extractContract } from "@rest-rpc/core";
import { router } from "../router.ts";

await writeFile("contract.json", JSON.stringify(extractContract(router)));
```

```json package.json
{
	"scripts": {
		"contract": "node --watch scripts/extract-contract.ts",
		"dev": "npm run contract & next dev"
	}
}
```

```ts client.ts
import { createClient } from "@rest-rpc/core";
import type { router } from "./router";
import contract from "./contract.json";

export const client = createClient(contract as unknown as typeof router, {
	origin: "http://localhost:3000",
});
```

## Limitations

The extracted contract has no schemas, so the client can't
[validate responses](/docs/client/fetch-client#response-validation), and
routes with [inferred responses](/docs/route-builder#return-responses) accept
any 2xx. If you need client-side validation, use a
[shared contract](/docs/contract-first).
