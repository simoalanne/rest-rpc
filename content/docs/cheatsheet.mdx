REST APIs with RPC-like ergonomics: an HTTP route builder with sensible
defaults, and typed clients that call the routes like ordinary functions.
Schemas are any [Standard Schema](https://standardschema.dev) (Zod, Valibot,
ArkType). Below are the common patterns, each a complete example. See the
[documentation](/docs/quickstart) for the rest.

| Package                                                                         | Contains                                                                        |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [`@rest-rpc/core`](https://npmx.dev/package/@rest-rpc/core)                     | Contracts, Fetch client, contract extraction, OpenAPI                           |
| [`@rest-rpc/server`](https://npmx.dev/package/@rest-rpc/server)                 | Route builder and handlers for Fetch runtimes, `@rest-rpc/server/node` for Node |
| [`@rest-rpc/tanstack-query`](https://npmx.dev/package/@rest-rpc/tanstack-query) | TanStack Query options and keys                                                 |

## Hello World

A route, an app and a typed client. The client here calls the app in the same
process, which is also how to test it.

See [Quickstart](/docs/quickstart)

```ts
import { createClient } from "@rest-rpc/core";
import { createApp, route } from "@rest-rpc/server";

const routes = {
	hello: route.get("/hello").handler(() => ({ message: "Hello" })),
};

const app = createApp(routes); // `export default app` to serve it on Bun, Deno or Workers

const client = createClient(routes, {
	origin: "http://localhost",
	fetch: app.fetch,
});
const { status, body } = await client.hello();
console.log(status, body.message); // 200 "Hello", typed from the handler
```

## Methods and Paths

A route without a method is a `POST` at its keys in the route tree. `:name`
segments are string params.

See [Route Builder](/docs/route-builder#choose-a-method-and-path)

```ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

const api = route.prefix("/api");

export const routes = {
	todos: {
		list: api.get("/todos").handler(() => [{ id: "1", title: "Ship" }]), // GET /api/todos
		get: api.get("/todos/:id").handler(({ params }) => ({ id: params.id })), // params.id: string
		create: api
			.body(z.object({ title: z.string() }))
			.handler(({ body }) => ({ id: "2", title: body.title })), // POST /api/todos/create
	},
};
```

## Request Validation

Params, query, headers and body are validated before the handler runs, and an
invalid request gets a `400`. Params, query and headers arrive as strings, so
their schemas coerce.

See [Validation](/docs/http-behavior/validation)

```ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

const search = route
	.get("/users/:id/todos")
	.params(z.object({ id: z.coerce.number<number>() }))
	.query(
		z.object({
			done: z.stringbool().optional(),
			tags: z.array(z.string()).optional(),
		}),
	)
	.headers(z.object({ "x-request-id": z.string() }))
	.handler(({ params, query, headers }) => ({
		userId: params.id, // number
		done: query.done, // boolean | undefined
		tags: query.tags ?? [], // sent as tags[]=a&tags[]=b
		requestId: headers["x-request-id"],
	}));
```

## Status, Headers and Cookies

Return the body, or `respond()` to set the rest of the response.

See [Return Responses](/docs/route-builder#return-responses)

```ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

const create = route
	.post("/todos")
	.body(z.object({ title: z.string() }))
	.handler(({ body, respond }) => {
		const todo = { id: crypto.randomUUID(), title: body.title };
		return respond(todo, {
			status: 201,
			headers: { location: `/todos/${todo.id}` },
			cookies: ["last-created=1; HttpOnly"],
		});
	});
```

## Defined Responses

Responses are inferred from the handler. Define them to validate them at
runtime and document them in OpenAPI.

See [Define Responses](/docs/route-builder#define-responses)

```ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

const todo = z.object({ id: z.string(), title: z.string() });

const create = route
	.post("/todos")
	.body(z.object({ title: z.string() }))
	.response(todo, { status: 201, headers: z.object({ location: z.string() }) })
	.response({ status: 202 }) // no body
	.handler(({ body, respond }) => {
		if (body.title.length > 100) return respond(undefined, { status: 202 });
		const created = { id: crypto.randomUUID(), title: body.title };
		return respond(created, {
			status: 201,
			headers: { location: `/todos/${created.id}` },
		});
	});
```

## Errors

Errors are thrown. A defined error is typed on the client, and any other
`RouteError` is still sent with its status.

See [Errors](/docs/http-behavior/errors)

```ts
import { createClient, isDefinedError, safe } from "@rest-rpc/core";
import { createApp, route } from "@rest-rpc/server";
import { z } from "zod";

const todos = new Map([["1", { id: "1", title: "Ship" }]]);

const routes = {
	get: route
		.get("/todos/:id")
		.error("TODO_NOT_FOUND", {
			status: 404,
			data: z.object({ id: z.string() }),
		})
		.handler(({ params, errors }) => {
			const todo = todos.get(params.id);
			if (!todo) throw errors.TODO_NOT_FOUND({ data: { id: params.id } });
			return todo;
		}),
};

const app = createApp(routes);
const client = createClient(routes, {
	origin: "http://localhost",
	fetch: app.fetch,
});

const { error, data } = await safe(client.get({ params: { id: "2" } }));
if (isDefinedError(error))
	console.log(error.code, error.data.id); // "TODO_NOT_FOUND" "2"
else if (error) throw error;
else console.log(data.body.title);
```

## Shared Errors

`routeError()` defines an error once, to throw it from any code and add it to
routes.

See [Define Errors](/docs/route-builder#define-errors)

```ts
import { route, routeError } from "@rest-rpc/server";
import { z } from "zod";

const TodoNotFound = routeError("TODO_NOT_FOUND", {
	status: 404,
	data: z.object({ id: z.string() }),
});

const todos = new Map([["1", { id: "1", title: "Ship" }]]);

const findTodo = (id: string) => {
	const todo = todos.get(id);
	if (!todo) throw new TodoNotFound({ data: { id } });
	return todo;
};

const get = route
	.get("/todos/:id")
	.error(TodoNotFound)
	.handler(({ params }) => findTodo(params.id));
```

## Middleware and Context

Middleware runs after validation, around the handler, and passes typed values
to it through context. Initial context comes from the host.

See [Middleware](/docs/middleware)

```ts
import { createApp, route } from "@rest-rpc/server";

const authenticated = route
	.$context<{ headers: Headers }>() // provided by the app below
	.error("UNAUTHORIZED", { status: 401 })
	.use(({ context, errors, next }) => {
		const token = context.headers.get("authorization");
		if (!token) throw errors.UNAUTHORIZED();
		return next({ context: { user: { id: token } } });
	});

const routes = {
	me: authenticated.get("/me").handler(({ context }) => context.user), // user is typed
};

export default createApp(routes, {
	context: (request) => ({ headers: request.headers }),
});
```

## Metadata

Routes describe themselves to shared middleware with metadata of a declared
shape.

See [Metadata](/docs/middleware#metadata)

```ts
import { route } from "@rest-rpc/server";

const base = route
	.$meta<{ access: "public" | "signed-in" }>()
	.$context<{ user?: string }>()
	.error("UNAUTHORIZED", { status: 401 })
	.use(({ route, context, errors, next }) => {
		if (route.meta?.access !== "public" && !context.user)
			throw errors.UNAUTHORIZED();
		return next();
	});

const health = base
	.get("/health")
	.meta({ access: "public" })
	.handler(() => "ok");
const profile = base
	.get("/profile")
	.meta({ access: "signed-in" })
	.handler(({ context }) => context.user);
```

## Server-Sent Events

Return an async iterable to stream events. The client iterates them.

See [Server-Sent Events](/docs/streaming)

```ts
import { createClient } from "@rest-rpc/core";
import { createApp, route, sse, sseEvent } from "@rest-rpc/server";
import { z } from "zod";

const routes = {
	ticks: route
		.get("/ticks")
		.response(sse(z.object({ count: z.number() }))) // optional, validates each event
		.handler(async function* ({ signal }) {
			for (let count = 1; count <= 3 && !signal.aborted; count++) {
				yield sseEvent({ count }, { id: String(count) });
			}
		}),
};

const app = createApp(routes);
const client = createClient(routes, {
	origin: "http://localhost",
	fetch: app.fetch,
});

const { body } = await client.ticks();
for await (const event of body) console.log(event.id, event.data.count);
```

## Other Content Types

A body is JSON unless a `content-type` header says otherwise. The route
declares it in its headers schemas.

See [Encoding and Content Types](/docs/http-behavior/encoding#bodies)

```ts
import { route } from "@rest-rpc/server";
import { z } from "zod";

const importTodos = route
	.post("/todos/import")
	.headers(z.object({ "content-type": z.literal("text/csv") }))
	.body(z.string())
	.response(z.string(), {
		headers: z.object({
			"content-type": z.literal("text/plain").default("text/plain"),
		}),
	})
	.handler(({ body }) => `${body.split("\n").length - 1} todos imported`);

// The client sends it with the header: { headers: { "content-type": "text/csv" }, body: csv }
```

## Raw and Static Responses

Return a Fetch `Response` for anything else, such as a redirect. A route that
always sends the same response is `.static()`, built once.

See [Raw Responses](/docs/route-builder#raw-responses)

```ts
import { route } from "@rest-rpc/server";

const download = route
	.get("/files/:id")
	.handler(({ params }) =>
		Response.redirect(`https://cdn.example.com/${params.id}`, 302),
	);

const health = route.get("/health").static({ ok: true });
```

## Interceptors

Interceptors run around every request, routing included, for what rest-rpc
leaves to the app, such as API keys, CORS and error reporting.

See [Interceptors](/docs/server/interceptors)

```ts
import {
	createApp,
	errorResponse,
	interceptor,
	onError,
	route,
	routeError,
} from "@rest-rpc/server";

const Forbidden = routeError("FORBIDDEN", { status: 403 });

const apiKey = interceptor(({ request, next }) => {
	if (request.headers.get("x-api-key") !== "secret") throw new Forbidden();
	return next();
});

const cors = interceptor(async ({ next }) => {
	const response = await next();
	const copy = new Response(response.body, response); // its headers may be immutable
	copy.headers.set("access-control-allow-origin", "*");
	return copy;
});

const routes = { hello: route.get("/hello").handler(() => "Hello") };

export default createApp(routes, {
	interceptors: [
		cors,
		interceptor(({ next }) => next().catch(errorResponse)), // errors reach cors as responses
		onError((error) => console.error(error)), // every error, with its cause
		apiKey,
	],
});
```

## Node

`@rest-rpc/server/node` serves the same routes with `node:http`.

See [Node](/docs/server/node)

```ts
import { createServer } from "node:http";
import { route } from "@rest-rpc/server";
import { createApp } from "@rest-rpc/server/node";

const routes = { hello: route.get("/hello").handler(() => "Hello") };

createServer(createApp(routes)).listen(3000);
```

## Frameworks

Mount the routes in a framework under one route, or register each on its
router.

See [Framework Integration](/docs/server/framework-integration)

```ts
import { Hono } from "hono";
import { createCatchAllHandler, route } from "@rest-rpc/server";

const routes = { hello: route.get("/hello").handler(() => "Hello") };
const handler = createCatchAllHandler(routes);

const app = new Hono();
app.all("/api/*", async (c) => {
	const result = await handler(c.req.raw, { mountPath: "/api" });
	return result.matched ? result.response : c.notFound();
});

export default app;
```

## Browser Clients

A bundler macro runs `extractContract()` at build time and inlines the routes'
methods, paths, statuses and error codes, so no server code ships. Bun runs
macros itself, and Vite and other bundlers with `unplugin-macros`.

See [Contract Extraction](/docs/client/contract-extraction)

```ts
// client/contract.ts
import { extractContract } from "@rest-rpc/core";
import { routes } from "../server/routes.ts";

export function getApi() {
	return extractContract(routes);
}
```

```ts
// client/api.ts
import { createClient } from "@rest-rpc/core";
import { getApi } from "./contract.ts" with { type: "macro" };

export const client = createClient(getApi(), {
	origin: "https://api.example.com",
});
```

```ts
// vite.config.ts, not needed with Bun
import Macros from "unplugin-macros/vite";
import { defineConfig } from "vite";

export default defineConfig({ plugins: [Macros()] });
```

## Client Options

Headers for every request, the server's mount path, and interceptors around
each request.

See [Fetch Client](/docs/client/fetch-client#client-options)

```ts
import { clientInterceptor, createClient } from "@rest-rpc/core";
import { route } from "@rest-rpc/server";

const routes = { hello: route.get("/hello").handler(() => "Hello") };

const logging = clientInterceptor(async ({ request, next }) => {
	const response = await next();
	console.log(request.method, request.url, response.status);
	return response;
});

const client = createClient(routes, {
	origin: "https://api.example.com",
	mountPath: "/api",
	globalHeaders: {
		authorization: () => `Bearer ${localStorage.getItem("token")}`,
	},
	interceptors: [logging],
	timeoutMs: 10_000,
});
```

## TanStack Query

Query and mutation options for each route, with typed keys.

See [TanStack Query](/docs/client/tanstack-query)

```tsx
import { createClient } from "@rest-rpc/core";
import { route } from "@rest-rpc/server";
import { createTanstackQueryUtils } from "@rest-rpc/tanstack-query";
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { z } from "zod";

const routes = {
	todos: {
		list: route.get("/todos").handler(() => [{ id: "1", title: "Ship" }]),
		create: route
			.body(z.object({ title: z.string() }))
			.handler(({ body }) => body),
	},
};

const restrpc = createTanstackQueryUtils(
	createClient(routes, { origin: "https://api.example.com" }),
);

export function Todos() {
	const queryClient = useQueryClient();
	const todos = useQuery(
		restrpc.todos.list.queryOptions({ select: (response) => response.body }),
	);
	const create = useMutation(
		restrpc.todos.create.mutationOptions({
			onSuccess: () =>
				queryClient.invalidateQueries({
					queryKey: restrpc.todos.list.queryKey(),
				}),
		}),
	);
	return (
		<button onClick={() => create.mutate({ body: { title: "New" } })}>
			{todos.data?.length ?? 0} todos
		</button>
	);
}
```

## Contract-first

Define the routes in a shared contract with `@rest-rpc/core`, and implement
them on the server. The client uses the contract directly, schemas included.

See [Contract-first](/docs/contract-first)

```ts
import { createClient, route } from "@rest-rpc/core";
import { createApp, implement } from "@rest-rpc/server";
import { z } from "zod";

const api = {
	todos: {
		get: route
			.get("/todos/:id")
			.response(z.object({ id: z.string(), title: z.string() }))
			.error("TODO_NOT_FOUND", { status: 404 }),
	},
};

const routes = {
	todos: {
		get: implement(api.todos.get).handler(({ params }) => ({
			id: params.id,
			title: "Ship",
		})),
	},
};

const app = createApp(routes);
const client = createClient(api, {
	origin: "http://localhost",
	fetch: app.fetch,
	validateResponses: true,
});
```

## Local Calls

`call()` runs one route in process, through validation and middleware, without
HTTP.

See [Local Client](/docs/client/local-client)

```ts
import { call, route } from "@rest-rpc/server";
import { z } from "zod";

const double = route
	.get("/double/:n")
	.params(z.object({ n: z.coerce.number<number>() }))
	.handler(({ params }) => params.n * 2);

const { body } = await call(double, { params: { n: 21 } });
console.log(body); // 42
```

## OpenAPI

An OpenAPI document from the same routes, with a converter for your schema
library.

See [OpenAPI](/docs/openapi)

```ts
import { createOpenApiDocument, route } from "@rest-rpc/server";
import { z } from "zod";

const routes = {
	todos: {
		list: route
			.get("/todos")
			.response(z.array(z.object({ id: z.string(), title: z.string() })))
			.openAPI({ summary: "List todos", tags: ["Todos"] })
			.handler(() => [{ id: "1", title: "Ship" }]),
	},
};

const document = createOpenApiDocument(routes, {
	info: { title: "Todo API", version: "1.0.0" },
	schemaConverter: (schema, io) => z.toJSONSchema(schema as z.ZodType, { io }),
});
```

## Type Helpers

Reuse a route's types in code outside it, such as a service written apart
from its route.

See [Type Helpers](/docs/route-builder#type-helpers)

```ts
import type { InferClientResponse } from "@rest-rpc/core";
import { route, type InferServerRequest } from "@rest-rpc/server";
import { z } from "zod";

const update = route.patch("/todos/:id").body(z.object({ title: z.string() }));

const updateTodo = ({ params, body }: InferServerRequest<typeof update>) => ({
	id: params.id,
	title: body.title,
});

const routes = { update: update.handler(updateTodo) };

type UpdateResponse = InferClientResponse<typeof routes.update>; // { status: 200; body: { id; title }; ... }
```
